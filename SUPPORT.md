# Support

ACN Preflight has separate channels for integration support, product questions, and security reports.

## Public integration support

For reproducible problems in the Python client, CLI, MCP integration, packaging, examples, or public documentation, open a GitHub issue and include the package version or commit plus a minimal reproduction.

## Product and commercial questions

For deployment, custom agent infrastructure, commercial integrations, or other Abacore engineering work, use the contact channel published at https://abacore.net.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

Never include access tokens, private keys, wallet secrets, seed phrases, deployment credentials, or unrelated customer data in a support request.
